# 河图歌词集

一个精美的古风歌词展示网站，收录了河图的古风歌曲歌词。

🔗 **在线访问**: https://AiYuSherry.github.io/hetu-lyrics-website/

## 功能特点

- 🎵 完整的歌曲列表，支持按年份、作词人筛选
- 🔍 全局搜索功能，支持歌名、歌词、作词人搜索
- 📊 数据统计页面，展示词频分析、作词人统计等
- ❤️ 收藏功能，可以收藏喜欢的歌曲
- 💬 评论功能，可以为每首歌添加评论
- 📝 歌词片段分享
- 📱 响应式设计，支持移动端访问

## 技术栈

- React + TypeScript
- Vite
- Tailwind CSS
- shadcn/ui

## 数据来源

歌词数据来源于网络收集，仅供学习交流使用。

## 本地开发

```bash
cd app
npm install
npm run dev
```

## 构建

```bash
cd app
npm run build
```

## 部署

本项目使用 GitHub Actions 自动部署到 GitHub Pages。
