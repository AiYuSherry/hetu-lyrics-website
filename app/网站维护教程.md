# 河图歌词集网站维护教程

## 一、如何更新歌词数据

### 1. 准备歌词数据文件

将新的歌词数据整理为以下格式的JSON文件：

```json
[
  {
    "id": 1,
    "name": "歌曲名称",
    "year": "2007-01-01",
    "year_only": "2007",
    "album": "专辑名称",
    "lyricist": "作词人",
    "composer": "作曲人",
    "arranger": "编曲人",
    "singer": "演唱者",
    "initial": "S",
    "lyrics": "完整歌词内容..."
  }
]
```

### 2. 更新数据文件

1. 打开项目文件夹 `app/src/data/`
2. 找到 `songs_data.json` 文件
3. 用新的歌词数据替换原有内容
4. 保存文件

### 3. 重新构建网站

在终端中执行以下命令：

```bash
cd /mnt/okcomputer/output/app
npm run build
```

### 4. 部署更新

构建完成后，网站会自动更新。如果部署到外部服务器，需要将 `dist` 文件夹中的内容上传到服务器。

## 二、如何查看网站访问数据

### 方法一：使用 Vercel Analytics（推荐）

如果网站部署在 Vercel 上：

1. 登录 Vercel 账号：https://vercel.com
2. 进入对应的项目页面
3. 点击顶部导航栏的 "Analytics" 标签
4. 查看访问量、访问来源、地理位置等数据

### 方法二：使用 Google Analytics

1. 注册 Google Analytics 账号：https://analytics.google.com
2. 创建新的媒体资源，获取跟踪 ID（如 `G-XXXXXXXXXX`）
3. 在 `index.html` 文件的 `<head>` 标签内添加以下代码：

```html
<!-- Google Analytics -->
<script async src="https://www.googletagmanager.com/gtag/js?id=G-XXXXXXXXXX"></script>
<script>
  window.dataLayer = window.dataLayer || [];
  function gtag(){dataLayer.push(arguments);}
  gtag('js', new Date());
  gtag('config', 'G-XXXXXXXXXX');
</script>
```

4. 重新构建并部署网站
5. 24小时后在 Google Analytics 后台查看数据

### 方法三：使用百度统计

1. 注册百度统计账号：https://tongji.baidu.com
2. 添加网站，获取统计代码
3. 在 `index.html` 文件的 `<head>` 标签内添加百度统计代码
4. 重新构建并部署网站

## 三、常见问题

### Q1: 如何添加新的词作人？

直接在 `songs_data.json` 中添加包含新词作人的歌曲数据即可，系统会自动识别并统计。

### Q2: 如何修改网站样式？

1. 全局样式：修改 `src/App.css`
2. 组件样式：修改对应组件文件中的 Tailwind CSS 类名
3. 颜色主题：修改 `tailwind.config.js` 中的颜色配置

### Q3: 如何备份数据？

定期备份以下文件：
- `src/data/songs_data.json` - 歌词数据
- `public/` 文件夹 - 静态资源

### Q4: 网站访问速度慢怎么办？

1. 启用 CDN 加速
2. 压缩图片资源
3. 使用 Vercel 或 Netlify 等静态托管服务
